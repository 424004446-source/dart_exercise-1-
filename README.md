# dart_exercise-1-

Dart Fundamentals – Student Grade Calculator
Scenario

This program is a simple Student Grade Calculator. It stores the student's name, activity grade, project grade, and passing status. It calculates the final grade using arithmetic operators and checks whether the student passed using comparison operators.

Data Types Used

String – stores the student's name

int – stores the activity grade

double – stores the project grade and final grade

bool – stores the student's passing status

Operators Used

The program demonstrates arithmetic operators such as +, /, -, and %. It also uses comparison operators such as >= to determine whether the student passed and whether the final grade is excellent.
